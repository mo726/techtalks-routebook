# RouteBook

RouteBook is a Next.js App Router application with TypeScript and Tailwind
CSS 4. The domain work currently covers exact money arithmetic, validation
schemas, and the payment service that sits in front of the API-10 endpoint.

## Getting started

Node.js 24 is the supported runtime (see `.nvmrc`).

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

The project uses the Next.js App Router, TypeScript, and Tailwind CSS 4.

Useful checks:

```bash
npm run lint
npm run typecheck
npm run build
```
